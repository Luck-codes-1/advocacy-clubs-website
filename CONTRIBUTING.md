# Contributing

Thanks for helping shape the Advocacy Clubs website. The project is currently
in its planning stage; it does not yet contain application code.

## Before contributing

- Check the README and existing issues to understand current plans.
- For a substantial change, open an issue first so the scope can be discussed.
- Keep contributions focused and explain the problem they address.

## Submitting a change

1. Create a branch for your change.
2. Make the smallest complete change that addresses the issue.
3. Check your changes for clarity and consistency.
4. Open a pull request describing the motivation, the changes, and any relevant
   screenshots or testing.

Please follow the Code of Conduct in all project spaces. Contribution
requirements may be updated when the project's technology stack is selected.
