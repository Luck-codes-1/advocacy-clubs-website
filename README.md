# Advocacy Clubs Website

A website project for advocacy clubs. This repository is a documentation and
planning scaffold; it currently contains no application code.

## Project status

The project is at its initial setup stage. The intended audience, features, and
technology stack have not yet been defined.

## Getting started

There is no application to run yet. Setup and development instructions will be
added after the technology stack is chosen.
