# Security Policy

## Project status

This repository is an initial planning scaffold and does not yet contain
application code or a deployed website.

## Reporting a vulnerability

If you discover a security issue, report it privately to the project
maintainers. Use GitHub's private vulnerability reporting feature if it is
enabled for this repository. Do not include vulnerability details, personal
data, or exploit steps in a public issue.

The maintainers will review reports and coordinate any necessary fixes and
disclosure after the project has security-sensitive functionality.
